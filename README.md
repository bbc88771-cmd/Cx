# Карта наличия топлива и очередей на АЗС — Россия

Онлайн-карта на базе Leaflet + OpenStreetMap с крауд-сорсинговыми отчётами о наличии
топлива и очередях на АЗС по всей России. Пользователи сами отмечают статус станций,
данные хранятся в Firebase Firestore и обновляются на карте в реальном времени у всех
посетителей.

## Возможности

- Карта России с цветными маркерами: наличие топлива, очередь, ограничение отпуска, нет топлива.
- Отчёты старше 24 часов автоматически помечаются как устаревшие (серый цвет).
- Фильтр по видам топлива (АИ-92 / АИ-95 / АИ-98 / ДТ / Газ).
- Форма добавления отчёта: выбор города, координаты по клику на карте или по геолокации,
  статус, длина очереди, комментарий.
- Работает как статический сайт (GitHub Pages), без сервера — вся логика на клиенте,
  хранилище данных — Firebase Firestore.
- Если Firebase не настроен, приложение работает в демо-режиме (данные только в
  локальном браузере), с явным предупреждением пользователю.

## Быстрый старт: настройка Firebase (бесплатно, ~5 минут)

1. Зайдите на https://console.firebase.google.com и создайте новый проект.
2. В разделе **Build → Firestore Database** нажмите «Create database», выберите режим
   **production** и любой ближайший регион.
3. Перейдите на вкладку **Rules** в Firestore и вставьте содержимое файла
   [`firestore.rules`](./firestore.rules) из этого репозитория, затем нажмите «Publish».
4. В настройках проекта (шестерёнка → **Project settings** → вкладка **General**) в
   разделе «Your apps» добавьте Web-приложение (иконка `</>`), название — любое.
5. Скопируйте объект `firebaseConfig`, который покажет Firebase, и вставьте значения в
   файл [`js/firebase-config.js`](./js/firebase-config.js) вместо плейсхолдеров
   `YOUR_API_KEY`, `YOUR_PROJECT` и т.д.
6. Закоммитьте изменённый `js/firebase-config.js` — эти значения не секретны, это
   публичный клиентский конфиг, безопасность обеспечивает Firestore Rules.

Пока `firebase-config.js` не заполнен, сайт работает в демо-режиме на localStorage —
это удобно для локальной проверки вёрстки, но данные не будут общими для всех
посетителей.

## Публикация через GitHub Pages

1. В настройках репозитория: **Settings → Pages**.
2. Source: **Deploy from a branch**, Branch: выберите нужную ветку и папку `/ (root)`.
3. Сохраните — сайт станет доступен по адресу вида
   `https://<username>.github.io/<repo>/`.

Никакой сборки не требуется — это чистый статический HTML/CSS/JS.

## Структура проекта

```
index.html            — разметка страницы (карта, панель фильтров, форма отчёта)
css/style.css          — стили, адаптивная раскладка для мобильных
js/app.js              — инициализация карты, Firebase, рендер маркеров, обработка формы
js/firebase-config.js  — конфиг Firebase-проекта (заполните своими значениями)
js/cities.js           — список городов России для автодополнения/перехода на карте
firestore.rules        — рекомендуемые правила безопасности Firestore
```

## Модель данных

Каждая АЗС — один документ в коллекции `stations`, идентификатор строится из округлённых
координат (`lat.toFixed(3)_lng.toFixed(3)`), поэтому повторные отчёты по одной и той же
станции обновляют существующую точку, а не плодят дубликаты.

```json
{
  "city": "Москва",
  "address": "Лукойл, Ленинский проспект 10",
  "lat": 55.7558,
  "lng": 37.6173,
  "status": "queue",
  "fuelTypes": { "92": true, "95": true, "dt": false, "gas": false },
  "queueCars": 12,
  "note": "Очередь около 30 минут",
  "reportCount": 3,
  "lastReporter": "r-ab12cd34",
  "createdAt": "<серверный таймстемп>",
  "updatedAt": "<серверный таймстемп>"
}
```

## Ограничения

- Данные полностью зависят от пользователей — точность и достоверность не
  гарантируются, это не официальный источник.
- Простая защита от спама реализована только на уровне валидации полей в
  Firestore Rules; для продакшена стоит добавить App Check и/или ограничение по IP
  через Cloud Functions.
